# Admin App — Complaint & Feedback Management

Flutter admin panel: dashboard stats, complaint triage, status & response, category management, user list.

## Run
```bash
flutter create . --project-name complaint_admin --platforms=android,ios,web,linux,macos,windows
flutter pub get
flutter run -d chrome   # or any device
```

Edit backend URL in `lib/core/config.dart`.

Default admin credentials: `admin@example.com` / `admin123`.
